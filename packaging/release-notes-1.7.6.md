ASA v1.7.6：APK 交互与下载修复、文件夹发送

### APK 修复
- 切后台/锁屏会中断更新 APK 下载
  - 更新下载移到前台服务，通知栏显示进度，离开设置页也不会取消
  - 下载完成后点击通知即可打开应用安装
- 打开输入框不会滚到最新消息
  - 聚焦输入框、选择回复时自动滚到底部
- 点击聊天区上方空白处无法收起输入法
  - 点击消息区空白处会清除焦点并隐藏键盘
- 更多菜单内容过多
  - 改为从右侧滑出的边栏，可滚动，不再使用拥挤的下拉列表
- 通话期间离开频道界面会被拉回
  - 记住上次所在页面，Activity 重建时不再强制回到聊天页
- 引用消息
  - 左右滑动都可触发回复，短消息也能触发（阈值降低到 40dp）
  - 滑动时气泡跟随移动并淡入回复图标
  - 引用预览减少行数，选择回复时自动滚到底部，避免遮挡
- 新消息
  - 不再强制跳到底部；在顶部显示“N 条新消息 · 点击查看”
  - 只有位于底部或自己发送消息时才自动滚动
- 消息打叉
  - 长按消息 → 复制文本 / 回复 / 标记为问题
  - 标记后显示红框和“× 已标注问题”，本地持久化，不提供撤销
- 默认下载路径
  - Android 11+ 默认保存到公共 `Download/ASA`
  - 首次会请求“所有文件访问”，拒绝时回退应用私有目录
- 语音房
  - 加入中的重复命令、麦克风启动失败后的重试循环已加保护，避免反复弹提示
- 文件夹发送
  - 选择接收人后可选择“文件夹”，递归发送其中每个文件
  - 单个文件夹最多 200 个文件，文件名带相对目录前缀避免重名

### TUI
- `/send` 支持目录递归和通配符
  - 例如 `/send bob ~/Pictures/*.jpg`、`/send @all ./docs`
  - 每个文件单独发起传输，最多 200 个

### 验证
- Rust：80 unit + 9 e2e 通过
- Android：Kotlin 编译通过，arm64 / x86_64 release APK 构建通过
- Windows 交叉编译通过
- TUI 通配符/目录展开单元测试通过

### 兼容性
- 版本号 1.7.6，Android `versionCode 26`
- 桌面/Android 配置格式不变
- 公共 `Download/ASA` 需要 Android 11+ 的“所有文件访问”权限
